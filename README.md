# 门店AI顾问

面向实体门店的 AI 短视频 SaaS 演示平台。终端客户通过 H5 使用经营诊断、营销策划、智能客服、短视频内容策划与真人口播视频任务，无需接触底层 AI、视频供应商或第三方后台。

## 本地预览

运行 node server.js，然后访问 http://localhost:4173。

## 统一接口

| 接口 | 用途 |
| --- | --- |
| GET /api/bootstrap | 当前用户、门店与产品能力上下文 |
| GET /api/agents | 可调用的 AI 能力目录 |
| GET /api/tasks | 统一任务中心与执行状态 |
| POST /api/tasks | 创建 AI 任务；视频类任务统一进入真人口播成片链路 |

接口仅返回面向门店客户的业务模型，不泄露供应商或内部系统接入细节。当前为可运行的内存演示实现；生产接入时可在不改变 H5 API 契约的情况下替换服务层。
