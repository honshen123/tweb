# 门店AI顾问

面向实体门店的 AI 短视频 SaaS 服务基线。终端客户通过 H5 使用经营诊断、营销策划、智能客服、短视频内容策划与真人口播视频任务，无需接触底层 AI、视频供应商或第三方后台。

## 本地预览

复制 .env.example 中的运行参数后，执行 npm start，然后访问 http://localhost:4173。

## 统一接口

| 接口 | 用途 |
| --- | --- |
| GET /api/bootstrap | 当前用户、门店与产品能力上下文 |
| GET /api/agents | 可调用的 AI 能力目录 |
| GET /api/tasks | 统一任务中心与执行状态 |
| POST /api/tasks | 创建 AI 任务；视频类任务统一进入真人口播成片链路 |

接口仅返回面向门店客户的业务模型，不泄露供应商或内部系统接入细节。任务创建支持 Idempotency-Key 请求头以防止重复提交；所有响应返回 X-Request-Id，且默认携带防嵌入和防 MIME 嗅探安全响应头。

## 商用接入清单

此仓库提供可运行的服务与 API 契约基线。上线前，总承包方应在保持现有 API 契约的前提下完成以下交付：

1. 使用受管数据库替换演示内存存储，并为任务、素材、发布记录和审计日志实施备份、保留与恢复策略。
2. 对接企业微信服务号 OAuth；在网关执行租户隔离、RBAC、限流、WAF、HTTPS、密钥托管和签名校验。
3. 将内容智能体与真人口播成片服务置于服务端适配器；用队列、回调验签、重试/死信队列与可观测性追踪打通任务状态。
4. 以真实门店数据完成性能、安全、兼容性、容灾与验收测试，并建立监控告警和 7×24 运行值守。
